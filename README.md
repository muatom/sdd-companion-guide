# המדריך המלווה ל-SDD

מדריך מלווה ל-Spec-Driven Development לצוותי המוצר והפיתוח: מה השיטה, מסלול למידה של יומיים, והשיטה כפי שהופעלה בפועל בפרויקט הגמל להשקעה.

- **הדף:** `index.html`, קובץ אחד בלי שלב בנייה. נפתח בכל דפדפן, במחשב ובטלפון.
- **הקראה קולית:** לכל פרק יש הקראה בעברית (`audio/`), שנוצרה ב-ElevenLabs, ותמליל מלא בתוך הדף.
- **עיצוב:** מערכת העיצוב של מגדל. הפונט והלוגו ב-`fonts/` וב-`assets/`.
